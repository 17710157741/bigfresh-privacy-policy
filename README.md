# BigFresh privacy policies

Public privacy-policy website for BigFresh games. Contact: 17710157741@163.com.

## Enable free GitHub Pages hosting

1. Open repository Settings → Pages.
2. Select Deploy from a branch.
3. Select main and / (root), then Save.
4. Enable Enforce HTTPS if available. Wait for the deployment to complete.
5. Check the policy in a signed-out browser before using its URL.

Website: https://17710157741.github.io/bigfresh-privacy-policy/

## Policy scope

The published notice covers the current stage without AppLovin integration, based on developer-provided feature information. It is not the final disclosure for a future advertising-enabled release. Audit the actual release build and update this policy and Google Play Data safety declarations before launch.

AppLovin may not be initialized or used for users who qualify as children under applicable law. A broad audience including children requires appropriate audience handling before advertising integration. Do not treat consent=false or non-personalized ads as permission to initialize AppLovin for children.

Sources:
- https://support.applovin.com/en/max/android/overview/privacy
- https://legal.applovin.com/privacy/
- https://support.google.com/googleplay/android-developer/answer/9893335

Add future game policies in separate directories and link them from index.html. Never commit SDK secrets, credentials, or game signing keys here.
